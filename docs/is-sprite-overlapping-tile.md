# Is Sprite Overlapping Tile

Checks to see if a Sprite is overlapping a :ocation with the given tile Image in a tilemap.

```sig
tileUtil.isSpriteOverlappingTile(null, null)
```

## Parameters

* **sprite**: the Sprite to check
* **tile**: the tile Image to check for
* **tilemap**: an optional tilemap to check against. If not specified, the current tilemap will be used


```package
arcade-tile-util=github:microsoft/arcade-tile-util
```
