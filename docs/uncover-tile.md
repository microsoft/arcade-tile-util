# Uncover Tile

Uncovers a tile at the given location if previously covered by coverTile or coverAllTiles.


```sig
tileUtil.uncoverTile(tiles.getTileLocation(0, 0))
```

## Parameters

* **location**: the location of the tile to uncover in the tilemap.
