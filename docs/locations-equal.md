# Locations Equal

Checks to see if two locations are equal. Equal means they have the same column and row.


```sig
tileUtil.locationsEqual(tiles.getTileLocation(0, 0), tiles.getTileLocation(0, 0))
```

## Parameters

* **a**: the first location to compare
* **b**: the second location to compare

```package
arcade-tile-util=github:microsoft/arcade-tile-util
```
